# Infostructure website

Minimal static website for **Infostructure Sweden AB**.

Live site: https://infostructure.se

The site is hosted with **GitHub Pages** and published from the `main` branch.

## Easiest way to update the site

Ask ChatGPT to update it.

The GitHub repository is connected to ChatGPT, so a request such as:

> Update the Infostructure website: change the text under Models to ...

or

> Add a new section to the Infostructure website, keeping the current design.

is enough for ChatGPT to edit the files in this repository directly.

After a change is committed to `main`, GitHub Pages normally republishes the site automatically within a few minutes.

## Manual update

For a simple text change:

1. Open `index.html` in this repository.
2. Click the pencil icon (**Edit this file**).
3. Make the change.
4. Click **Commit changes**.
5. Keep the commit on the `main` branch.
6. Wait a minute or two and reload https://infostructure.se.

For most content and design changes, `index.html` is the only file that needs editing.

## Files

- `index.html` — the complete website (HTML + CSS + logo artwork)
- `favicon.svg` — browser icon using the Infostructure symbol
- `README.md` — this documentation

## Domain and hosting

- Domain: `infostructure.se`
- DNS provider: Websupport
- Hosting: GitHub Pages
- GitHub Pages custom domain: `infostructure.se`

Websupport's **GitHub Pages** DNS preset is used for the website. Email DNS records (MX/TXT) are separate and should not be changed when updating the website.
